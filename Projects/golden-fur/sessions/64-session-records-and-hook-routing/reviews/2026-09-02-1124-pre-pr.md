## Non-blocking findings

### N1. `pr-guard.sh` review-folder match is loose — `.claude/hooks/pr-guard.sh`

`ls -d "$reviews_glob"/*"$leaf"*` matches by branch-leaf substring, so a
branch `foo` would be satisfied by a review folder for `foo-bar`. Acceptable
for a personal backstop; tighten to an exact-or-nested match if branches
ever collide.

### N2. `session-router.sh` regex is intentionally narrow

Only imperative PR phrasings trigger the finish route ("open a PR", "/pr",
"ship it", …). "wrap this up" / "we're done" will not. Documented in the
session testing doc's Open items.

### N3. `gitkeep-sweep.sh` `find` prune

Prunes `.git` and `node_modules` by name anywhere in the tree; a dir legit
named `node_modules` outside a package would also be skipped. Not a real
scenario here.
